## Audio Processing

Handles audio file input/output and real-time processing. Key features:
- Supports common audio formats (WAV, MP3, etc.)
- Provides audio normalization and filtering
- Integrates with transcription module
- Handles audio streaming for real-time processing

### Configuration
Adjust audio parameters in `src/config.yaml`:
- Sample rate
- Bit depth
- Input/output device settings

### Usage
Audio processing is automatically handled by the application when:
1. Loading audio files
2. Using real-time transcription
3. Exporting processed audio
